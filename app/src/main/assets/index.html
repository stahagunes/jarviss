Asistan

Yapay zekâ

Anthropic uyumlu adres; sonuna /v1 yazmana gerek yok. Not: Aracı servisler isteklerini (ekran içeriği, bildirimler dahil) görebilir.
Anahtarını girdikten sonra "Modelleri getir" ile erişebildiğin modelleri listele.
console.anthropic.com → Billing'den kredi yükle → API Keys → Create Key. Anahtarsız da temel komutlar çalışır. Anahtar sadece bu telefonda saklanır.

Ses

Uygulamanın içinde gömülü yapay zekâ sesi. İnternet, anahtar ve kota gerekmez.
Sola çektikçe ses kalınlaşır, Zeus'a yakışır.
console.cloud.google.com → Cloud Text-to-Speech API'yi etkinleştir → API ve Hizmetler → Kimlik bilgileri → API anahtarı oluştur. Faturalandırma hesabı istenir ama Chirp 3 HD seslerinde ayda 1 milyon karakter ücretsizdir.
"Sesleri getir" ile hesabındaki tüm Türkçe sesleri listeleyebilirsin.
aistudio.google.com → Get API key. Kart gerekmez. Günlük kota dolarsa telefon sesine geçer.
portal.azure.com → Speech service oluştur → fiyat katmanı Free F0 → Keys and Endpoint. Ayda 500.000 karakter ücretsiz.
Sesler kötüyse Google ses paketlerinden yüksek kaliteli Türkçe sesi indir.
